# React Blog

A small React blog app built with Vite. It demonstrates a simple component-based structure for rendering a header, an about section, and a list of blog articles.

## Features

- React 19 app bootstrapped with Vite
- Reusable components for header, about section, and article list
- Static article data rendered via props
- Simple stylesheet import and asset usage

## Project Structure

- `src/App.jsx` - main application component
- `src/main.jsx` - React entry point
- `src/Header.jsx` - header component
- `src/About.jsx` - about section component
- `src/ArticleList.jsx` - article list component
- `src/style.css` - global styles
- `src/assets/` - image and asset folder
- `public/` - static public assets

## Requirements

- Node.js 18 or later recommended

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open the app in your browser at the URL shown in the terminal.

## Build

Create a production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

## Notes

This project is configured as a Vite app with the `type` set to `module` in `package.json`.
